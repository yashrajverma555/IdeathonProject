# CareerPath AI

**Problem Statement 1 — Reverse-Engineered Career Roadmapper.**

AI-powered app that turns a dream career into a personalized, interactive roadmap with skills, milestones, projects, and timelines.

**Built with:** Flutter, Dart, n8n, DeepSeek AI.

**Features:** AI roadmap generation, interactive skill tree, progress tracking, interview questions, weekend projects, role comparison, and roadmap sharing.

**Architecture:** Flutter → n8n → AI Agent → DeepSeek → Structured JSON → Flutter.

**For:** Students and beginners planning their technical careers.
